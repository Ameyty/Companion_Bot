# Companion Bot

## Overview
A smart companion robot designed to assist users through voice interaction and environmental awareness. The system combines embedded hardware and AI-based processing to provide real-time guidance, feedback, and basic conversational support.

## Objectives
- Enable voice-based interaction with the user  
- Provide environmental awareness using sensors  
- Assist in navigation and daily tasks  
- Build a modular and scalable robotic system  

## System Architecture
- **Microcontroller (ESP32-C6):** Handles sensor data and communication  
- **Raspberry Pi:** Processes data, runs AI models, and manages interaction  
- **Sensors:** Camera, IMU, proximity sensors  
- **Output:** Audio feedback via earphones / speaker  

## Working Principle
The system continuously collects data from sensors such as camera and IMU. This data is processed on the Raspberry Pi to detect surroundings and understand user input. Based on the analysis, the bot provides feedback through audio or haptic signals.

## Features
- Voice interaction (Speech-to-Text and Text-to-Speech)  
- Real-time environment sensing  
- Obstacle detection and guidance  
- Modular architecture for easy upgrades  

## Components Used
- ESP32-C6  
- Raspberry Pi  
- Camera Module  
- MPU6050 IMU  
- Proximity Sensors (VL53L0X)  
- Audio Output Module  

## Applications
- Assistive technology for visually impaired users  
- Personal companion robotics  
- Smart navigation systems  

## Future Improvements
- Advanced AI conversation models  
- Mobile app integration  
- Cloud connectivity  
- Improved object detection accuracy
